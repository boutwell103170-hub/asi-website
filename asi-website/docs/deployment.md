# Deployment

1. Push repository to GitHub.
2. Create DigitalOcean App Platform app.
3. Select repository.
4. Set source directory to `/site`.
5. Deploy as a static site.
6. Test generated DigitalOcean URL.
7. Add `preview.asccinspection.net`.
